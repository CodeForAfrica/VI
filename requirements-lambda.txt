# Ingestion-only dependencies for the Lambda image.

# The Lambda now only ingests (see lambda_function.py); classification moved to
# the dedicated classifier container, which installs the full requirements.txt.
# The heavy ML stack (torch, transformers, tokenizers, peft, accelerate,
# scikit-learn, cleanlab, venn-abers, skops, sentencepiece) is intentionally

# are also excluded; the ingestion service imports only the packages below.

# the Lambda builds reproducibly and matches the tested classifier environment.
#

# `lambda_function.lambda_handler` before merging - runtime imports can't be fully
